1️⃣ Git Setup & Cloning

Step 1: Install Git

Download and install Git from https://git-scm.com/downloads.

During installation, leave all options as default and click Next all the way.

Step 2: Set up Git (one-time)

Open Git Bash (right-click anywhere → "Git Bash Here"). Run these commands:

git config --global user.name "Your Full Name" git config --global user.email "your-email@example.com"
⚠️ Important: Use the EXACT same email you used to sign up for GitHub. This is how the teacher will see your commits!

Step 3: Create a GitHub account

Go to https://github.com/signup and create an account.

Then send Theara your GitHub username so he can add you as a collaborator.

Step 4: Clone the project

Once Theara adds you, run this in Git Bash:

git clone https://github.com/ThearaGithub/Online-Shop-System.git cd Online-Shop-System git branch # You should see "* main"
✅ Done! You now have the full project on your computer. If you see the folder with files inside, you're ready for the next section.

2️⃣ Git Basics: Branch, Commit, Push, PR

You will use these 4 commands repeatedly. Here's what each does:

CommandWhat it does
git checkout -b NAMECreate a new branch (like a copy of the project just for you)
git add FILEStage a file — mark it ready to be saved
git commit -m "MESSAGE"Save your changes permanently with a description
git push origin BRANCHUpload your commits to GitHub

Your workflow (repeat for each part):

# Step A: Make sure you're on your branch git checkout your-branch-name # Step B: Create or edit files using VS Code / Notepad # (detailed in your task section below) # Step C: Save your changes to Git git add about.html # Stage the file git commit -m "Add about page structure" # Save # Step D: Upload to GitHub git push origin your-branch-name # Repeat Steps B-D for each part (4 parts total)

Creating a Pull Request (PR) — do this once at the end:

  1. Go to https://github.com/ThearaGithub/Online-Shop-System
  2. Click the "Pull Requests" tab
  3. Click the green "New Pull Request" button
  4. Set base: main ← compare: your-branch-name
  5. Click "Create Pull Request"
  6. Add a title like "Add FAQ page by Cheang Youpheng"
  7. Click "Create Pull Request"
  8. Tell Theara on Telegram that your PR is ready
❌ Never push to main directly. Always work on your own branch. Theara will review and merge your PR into main.
